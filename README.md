# GenLayer Spinner — Orbital Validator Shield

Animated spinner submission for the GenLayer Portal mission: **Design the GenLayer Spinner**.

### Concept
Features the **GenLayer Core Monogram** breathing with energetic consensus at the epicenter, encased by an orbital trajectory of 3 AI validator nodes converging on decisions.

### Features
- 60 FPS GPU-accelerated SVG keyframe animation.
- Unmistakable brand identity + AI consensus storytelling.
- High contrast on both Dark (`#0A0A12`) and Light (`#F8F9FA`) themes.
